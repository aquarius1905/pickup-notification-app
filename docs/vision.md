# Vision

## このアプリが解決したいこと

通所・訪問介護事業所と利用者・ご家族との送迎連絡を、電話ではなくLINEでスムーズに行えるようにする

## なぜ作るのか

家族が利用しているデイサービスでは、「あと10分ほどで到着します」といった連絡を電話で行っていました。

電話を受ける側にも掛ける側にも負担があり、「LINEで通知できればもっと便利なのでは」と感じたことが、このアプリを作り始めたきっかけです。

母がお世話になったデイサービスやデイケア・訪問リハビリ・訪問看護での経験から、介護職員とご家族の双方の負担を少しでも減らせるものを作りたいと考えています。

## 判断基準

- 介護職員の負担が減ること
- ご家族が安心して利用できること
- 操作説明がなくても使えること
- 現場で本当に役立つこと
- 技術よりも使いやすさを優先すること

## このアプリが目指す姿

- 通所系介護事業所で安心して利用できること
- ご家族への連絡を電話からLINEへ置き換えられること
- 現場の声を取り入れながら継続的に改善していくこと
