# Manual

## 対象

施設職員

---

## 作成方法

Google Docs

- 編集しやすい
- 画像を貼りやすい
- 共同編集も可能（将来必要なら）
- PDFへ簡単に出力できる
- 修正版をすぐ作れる

また、Google DocsならPDF化するだけでなく、必要に応じて共有リンクで最新版を案内することも可能。

モニター期間中は更新が入りやすいでしょうから、Google Docsを原本にして、配布用としてPDFを出力する運用が扱いやすい。

## マニュアル構成

1. はじめに
   - このアプリでできること
   - 利用に必要なもの
2. 初期設定
   - アプリのインストール
   - 招待コードの登録
3. 基本操作
   - 利用者の登録
   - 通所予定の登録・編集
   - 送迎通知の送信
   - キャンセルの登録
4. 各画面の説明
   - 送迎通知
   - 利用者管理
   - 予定確認
   - 通知履歴
   - 施設設定
5. よくある質問
   - 通知が届かない
   - 招待コードが使えない
   - LINEを変更した場合
6. お問い合わせ

スクリーンショットは、**「操作前 → 操作後」**の流れが分かるように配置する

## 必要なスクショ

□ ホーム

□ 利用者登録

□ QRコード

□ LINE画面

□ 通知履歴

## PDF作成時の注意

- 画像多め
